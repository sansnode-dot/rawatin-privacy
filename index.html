Privacy Policy - Rawatin

Terakhir diperbarui: 5 Oktober 2026

Rawatim adalah aplikasi pencatatan jadwal rutin yang dikembangkan oleh SansNode. Kami menghargai privasi pengguna dan berkomitmen untuk menjaga informasi yang digunakan di dalam aplikasi tetap aman dan transparan.

1. Data yang Disimpan

Rawatin dapat menyimpan informasi yang dimasukkan oleh pengguna, seperti:

  • Daftar jadwal perawatan/li>
  • Tanggal jadwal perawatan
  • Kategori
  • Riwayat jadwal perawatan

Data jadwal perawatan tersebut disimpan secara lokal pada perangkat pengguna. SansNode tidak memiliki server yang digunakan untuk menyimpan atau mengakses data transaksi pribadi tersebut.

2. Penggunaan Data

Informasi yang dimasukkan ke dalam aplikasi digunakan untuk membantu pengguna:

  • Mencatat jadwal perawatan
  • Mengingatkan jadwal perawatan
  • Melihat riwayat perawatan

3. Penyimpanan Lokali

Data utama aplikasi disimpan pada penyimpanan lokal perangkat pengguna. Data tersebut tidak dikirimkan ke server SansNode.

Apabila pengguna menghapus aplikasi atau menghapus data aplikasi melalui pengaturan perangkat, data lokal dapat ikut terhapus. Pengguna disarankan melakukan ekspor atau backup data secara berkala apabila diperlukan.

4. Notifikasi

Rawatin dapat meminta izin notifikasi untuk memberikan pengingat terkait jadwal perawatan berikut nya.

Pengguna dapat mengizinkan atau menolak notifikasi dan dapat mengubah pengaturan tersebut kapan saja melalui pengaturan perangkat Android.

5. Iklan dan Layanan Pihak Ketiga

Rawation dapat menggunakan layanan pihak ketiga seperti Google AdMob untuk menampilkan iklan.

Penyedia layanan iklan dapat mengumpulkan atau memproses informasi tertentu, seperti:

  • Informasi perangkat
  • Identifier perangkat atau advertising ID
  • Interaksi dengan iklan
  • Informasi diagnostik
  • Informasi terkait performa aplikasi

Pengumpulan dan pemrosesan data oleh layanan pihak ketiga tunduk pada kebijakan privasi masing-masing penyedia layanan.

Untuk informasi lebih lanjut mengenai bagaimana Google memproses data, pengguna dapat membaca kebijakan privasi Google: https://policies.google.com/privacy

6. Keamanan Data

Kami berupaya menjaga aplikasi tetap aman dan meminimalkan pengumpulan data pribadi. Karena data jadwal perawatan utama disimpan secara lokal pada perangkat, keamanan data juga bergantung pada keamanan perangkat pengguna.

Pengguna disarankan menggunakan fitur keamanan perangkat seperti PIN, password, sidik jari, atau fitur keamanan lainnya.

7. Berbagi Data

SansNode tidak menjual data jadwal perawatan pengguna dan tidak membagikan data jadwal perawatan lokal kepada pihak ketiga.

Layanan pihak ketiga yang digunakan aplikasi, seperti layanan iklan, dapat memproses data sesuai kebutuhan layanan dan kebijakan privasi mereka sendiri.

8. Penghapusan Data

Pengguna dapat menghapus data jadwal perawatan melalui fitur yang tersedia di dalam aplikasi.

Pengguna juga dapat menghapus seluruh data aplikasi dengan:

  • Menghapus data aplikasi melalui pengaturan Android
  • Menghapus atau uninstall aplikasi dari perangkat

9. Privasi Anak

Rawatin boleh di gunakan untuk anak-anak sebagai reminder jadwal anak-anak.

10. Perubahan Kebijakan Privasi

Kebijakan privasi ini dapat diperbarui dari waktu ke waktu apabila terdapat perubahan fitur, teknologi, layanan pihak ketiga, atau ketentuan yang berlaku.

Perubahan akan ditampilkan pada halaman ini dengan memperbarui tanggal "Terakhir diperbarui".
